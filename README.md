# V2X Multi-UAV Trust Handover Project

This project contains the NS-3 + Python pipeline for multi-UAV V2X trust handover experiments.

Main components:
- NS-3 simulation
- Edge AI trust server
- Cloud AI / ledger logic
- Edge-cloud bridge
- Trust coordinator
- Blockchain-style global ledger
- CUSUM / Bayesian / NASH detection
- Late-entry attacker experiments
- Handover-defense experiments

Project goals:
1. Study multi-UAV trust handover.
2. Analyze late-entry boundary attackers.
3. Evaluate CUSUM ON/OFF.
4. Add handover trust decay and post-handover probation.
5. Validate 2-UAV and 3-UAV scenarios.
