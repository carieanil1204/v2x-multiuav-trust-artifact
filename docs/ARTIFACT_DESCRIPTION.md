# Artifact Description

## Overview

This artifact accompanies the paper:

"Mobility-Aware Multi-UAV Edge–Cloud Trust Management for Falsified Vehicular Beacon Detection under Handover and Packet Loss"

The package provides the complete reproducibility materials for the experimental evaluation.

## Included Materials

The artifact contains:

- Locked experimental result CSV files
- Per-seed evaluation records
- Experiment manifest
- Result-to-paper-table mapping
- Automated verification scripts
- Version and integrity information

## Experimental Validation

All reported results were generated using:

- ns-3 based simulation framework
- 15 independent random seeds
- Final locked implementation
- Verified result summaries

## Verification

The artifact includes an automated verification script that checks the numerical values reported in the manuscript against the locked CSV files.

## Result Traceability

Every reported metric follows:

Paper Table → Experiment Manifest → Locked CSV → Per-seed Results → Simulation Logs
