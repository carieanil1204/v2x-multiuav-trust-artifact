# Experimental Artifact

This repository contains the locked experimental artifacts for:

"Mobility-Aware Multi-UAV Edge–Cloud Trust Management for
Falsified Vehicular Beacon Detection under Handover and Packet Loss"

## Contents

- Locked CSV result files
- Per-seed experimental records
- Result-to-table mapping
- Verification scripts

## Experimental Protocol

All primary experiments were executed using:

- ns-3 simulation framework
- 15 independent random seeds
- locked final implementation
- reproducible configuration files

## Result Traceability

Every numerical value reported in the manuscript can be traced to:

Paper Table → Aggregate CSV → Per-seed CSV → Simulation log

## Reproducibility

The artifact package is intended for reviewer verification.
